## Cómo trabajo

- **Simple primero.** Si un archivo de texto plano y un servidor Python resuelven el problema, no hace falta una base de datos ni un framework de JavaScript.
- **Respaldos, respaldos, respaldos.** Toda infraestructura que no se puede reconstruir es una deuda.
- **Que puedas no significa que debas.** Cada herramienta del stack tiene que justificar su lugar en la forma real de trabajar.
- **Co-construir.** El desacuerdo bien llevado produce mejores soluciones que el consenso apurado.
